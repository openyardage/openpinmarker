# Contributing

OpenPinMarker is a concept. What helps most now:

- measurements from real greens, against a surveyed point
- experience with the receivers, antennas and correction services named in
  the [README](README.md)
- a clamp or case design

Open an issue first for anything larger than a fix, so two people do not
build the same thing.

Contributions fall under the licence of the folder they go into (see
[LICENSE](LICENSE)). By opening a pull request you agree to that.
