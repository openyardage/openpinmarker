# Firmware

Not written yet. What it has to do:

- read the receiver and log its raw satellite data to the microSD card all
  round, for the calculation afterwards
- on a press, take the position once it has settled; one buzz on the phone
  when saved, three when there is no position yet
- talk to the phone over Wi-Fi
- install over USB from a web page, which also sets the club's key, one per
  marker, so a lost one can be switched off
